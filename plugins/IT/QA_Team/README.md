# IT QA team

A complete plugin for one team. Its marketplace entry is `it-qa`. Installing it adds only the skills below, not the Development team's.

| Skill | What it does |
|---|---|
| [`qa-test-plan`](skills/qa-test-plan/SKILL.md) | Builds a test plan and test cases from requirements or user stories. |
| [`qa-bug-report`](skills/qa-bug-report/SKILL.md) | Turns rough defect notes into a clear, reproducible bug report. |

Manifest: [`.codex-plugin/plugin.json`](.codex-plugin/plugin.json)
