# Test Plan

Create a structured test plan from the requirements, user stories, or acceptance criteria the user supplies.

- Map each test case to a requirement, with preconditions, steps, test data, and expected result.
- Cover happy paths, edge cases, negative cases, and regression risk; note what is out of scope.
- Flag ambiguous or untestable requirements as questions rather than assuming behavior.
