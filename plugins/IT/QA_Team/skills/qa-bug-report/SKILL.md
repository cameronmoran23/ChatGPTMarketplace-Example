# Bug Report

Turn rough notes, logs, or screenshot descriptions into a bug report a developer can act on.

- Include a short title, environment, numbered reproduction steps, expected versus actual result, and frequency.
- Suggest severity and priority with a brief rationale, and attach the relevant log or error excerpts supplied.
- Mark missing details as unknown; do not guess at root cause or invent reproduction steps.
