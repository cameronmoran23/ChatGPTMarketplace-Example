# Code Review

Review a supplied diff, pull request, or code snippet and report findings a reviewer would act on.

- Prioritize correctness bugs, security issues, and unhandled edge cases over style; rank findings by severity.
- Point to the exact file and line, explain the failure scenario, and suggest a concrete fix.
- Separate confirmed defects from questions or preferences; do not claim code was run or tested unless it was.
