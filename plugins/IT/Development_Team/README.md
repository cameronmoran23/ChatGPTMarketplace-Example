# IT Development team

A complete plugin for one team. Its marketplace entry is `it-development`. Installing it adds only the skills below, not the QA team's.

| Skill | What it does |
|---|---|
| [`dev-code-review`](skills/dev-code-review/SKILL.md) | Reviews a code change for correctness, risk, and maintainability, with findings ranked by severity. |
| [`dev-technical-design`](skills/dev-technical-design/SKILL.md) | Drafts a technical design document from requirements and system context. |
