# HR - Job Description Draft

A plugin containing a single skill. Its marketplace entry is `hr-job-description`. Installing it adds this skill and nothing else from HR.

The skill turns role requirements into a clear, inclusive job description. It separates essential from preferred qualifications and lists unknown details as questions.

| File | Purpose |
|---|---|
| [`.codex-plugin/plugin.json`](.codex-plugin/plugin.json) | Manifest for this skill alone. `skills` points at `./skill/`. |
| [`skill/SKILL.md`](skill/SKILL.md) | The skill instructions. |
| [`skill/agents/openai.yaml`](skill/agents/openai.yaml) | Display name and default prompt. |
